# HC-quintic-sextic

Code and data supporting the note *The Hodge conjecture for very general sums of binary quintics and sextics* (Kevin
Saller, 2026).

**Result.** For d = 5 or 6 and every m ≥ 1, the Hodge conjecture holds for the hypersurface
F_0(u_0,v_0) + … + F_m(u_m,v_m) = 0 in P^(2m+1) when F_0, …, F_m are very general binary forms of degree d. The note
also gives the dimension of the space of Hodge classes.

The proofs in the note do not use these computations. [`README.txt`](README.txt) gives the requirements, the rerun
instructions and what each script checks.

**Status:** draft, not yet peer reviewed.

**Disclosure:** the arguments and computations were produced with the assistance of an AI system (Claude, by
Anthropic). They were checked with separately written code and in separate internal reviews, which were also carried
out with AI assistance. What was not checked is listed in the note and in README.txt.
